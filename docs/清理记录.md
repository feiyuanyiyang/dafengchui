## 遇到的问题

1. **PyInstaller onefile 启动失败**：报 `Failed to create parent directory structure`，
   在把 TEMP 换到工作区后仍然出现；判断是当前 DSH 沙箱对 onefile 解压目录的限制。
   改用 **onedir** 后正常，`--selftest` 19/19、`--check-assets` 退出码 0。
   在普通桌面环境可以再试 onefile；命令见 `大风吹_V1_制作参考说明.md` 附录 F。
2. **T9 import 白名单**在打包后读不到 `game.py` 源码：已加
   `if getattr(sys, "frozen", False): return`，打包后 T9 直接跳过。
3. **pip 默认用户目录不可写**：改用 `%TEMP%\dafengchui_venv` 虚拟环境安装依赖。

## 重新打包（简述）

```powershell
python -m pip install pygame pyinstaller
python -m PyInstaller --noconfirm --clean --onedir --windowed ^
  --name dafengchui --add-data "assets;assets" ^
  --hidden-import PIL._tkinter_finder ^
  --collect-all pygame ^
  --exclude-module av ^
  game.py
```

要支持玩家导入 MP3/M4A，把 `--exclude-module av` 换成 `--collect-all av`（体积会明显增大）。
