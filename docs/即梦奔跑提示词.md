# 奔跑版提示词（双臂张开，像小飞机）

> 目标：把 walk A 换成更大幅度的奔跑动作；双臂向两侧斜后方伸直张开，
> 身体前倾，腿大步交替，头发和裙摆向后翻飞，表情元气可爱。
> 只描述动作，不写“原神/可莉”等 IP 名称，避免审核和跑偏。

## 1. 奔跑关键帧 A

```text
以参考图中的角色为唯一形象标准：同一张脸、同一蓝发、同一女仆装、
同一鲸鱼尾巴、同一头身比。只改变动作和镜头：

角色向右前方奔跑，身体保持右前3/4侧身约45°，身体前倾约15°；
双臂向身体两侧斜后方伸展张开（略高于肩，像小飞机滑翔），
五指张开，手臂不要弯曲抱在胸前，不是站立T-pose；
右腿大步向前迈出、左腿向后踢起，双脚离地，像小孩子开心地跑；
头发向身后飘起，白色围裙和藏青色裙摆向后翻飞，蝴蝶结有滞后感；
表情可爱元气：眼睛亮晶晶、张嘴笑、脸颊红润。

全身完整，双手和脚都不被裁切，画面横向留白足够；
纯绿色背景，无地面阴影、无文字、无水印、无速度线。
Q版游戏奔跑精灵图，粗描边，平涂，柔和体积感。
```

## 2. 奔跑关键帧 B

## 3. 奔跑循环视频（推荐，能一次拿到 8–12 帧）

```text
【图生视频】以上传的奔跑A为第一帧。
角色原地向右奔跑循环，固定机位：不移动、不缩放、不转镜头、不换背景。
双臂保持向身体两侧斜后方伸展张开（像小飞机），身体前倾；
双腿大幅交替，后腿踢起，头发和裙摆向后翻飞；
保持角色长相、蓝发、女仆装、3/4角度和绿色背景完全一致；
全身完整，手脚不裁切；不要文字、水印、地面阴影、速度线。

时长3秒，24fps，动作幅度大，首尾动作接近，方便循环。
```

## 5. 生成时的注意点

- 双臂张开很容易被画成“站立 T-pose”：一定要同时写“正在奔跑、身体前倾、双脚离地、后腿踢起”。
- 如果手臂还是收在胸前：降低参考强度到 0.6–0.65，并强调“手臂向两侧伸直张开”。
- 如果角色/服装开始漂：把参考强度提到 0.75–0.8。
- 手臂张开后画面会变宽：让即梦“横向留白足够、双手不要裁切”；导入时如果手被裁掉，游戏贴图画布现在是 125×135（身体居中，判定框随角色等比调整）。
- 奔跑帧建议 8 帧 @ 12–14 fps，比现在的 2 帧行走顺很多。
