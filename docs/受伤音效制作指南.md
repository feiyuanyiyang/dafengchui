# 受伤音效制作指南（简短非语言人声）

目标：制作 0.2–0.4 s 的“呃 / 呜 / 嗯 / 吸气 / 闷哼”类非语言受伤声，音色软糯少女，
并且能反复迭代、不依赖某个 TTS 的念稿能力。

---

## 结论：优先“真人短录音 + 声音转换”

TTS（包括 ElevenLabs 的普通 Text to Speech）擅长念句子，不擅长短促的非语言发声：
它会把“呃啊”读成带音节的“啊——”，很容易变成娇喘或拖长。真人短录音能保证
**惊讶感、重音、爆破点、长短**都由表演控制，转换只负责音色。

推荐流程：

1. **录**：手机录音机即可，安静房间、离嘴 10–20 cm，录 10–20 条。
   - 尖锐：短促“呃！”（像被打到，先出气再出声）
   - 软：带哭腔的“呜……”
   - 闷：闭嘴的“嗯……”（鼻音、忍住痛）
   - 每条 0.3–1 s，不要背景音乐/风扇声；多录几条挑最好的。
2. **转音色**（任选其一）：
   - **ElevenLabs Voice Changer**（Speech to Speech）——最省事，上传录音选音色即可。
   - **Seed-VC** / **RVC** 的 Hugging Face Space——免费在线，用 10–30 s 参考音频做零样本/少样本音色转换。
   - **GPT-SoVITS**（本地，少样本克隆）——想长期固定 DeepSeek娘 音色时最合适。
   - 参考音频必须是你有授权的：自己录、朋友录、或明确允许使用的语音；不要直接拿视频里的歌声去克隆。
3. **裁与调**：用本仓库的 `tools/audio/make_hurt_voice.py` 裁掉首尾静音、降调、控制时长、提亮、去闷：
   ```powershell
   python tools/audio/make_hurt_voice.py 录音.wav `
       --pitch -2 --punch 0.6 --fade-in 0.008 --skip 0 `
       --duration 0.28 --cutoff 9000 --lpf-order 3 `
       --presence 12 --presence-high 7500 --low-cut 220 --trim-threshold 0.0025
   ```
4. **试听**：`python tools/audio/audition_hurt.py --install <文件名前缀>`。

优点：可控、自然、不会“念台词”；缺点：需要开口录几条（不想露脸只出声即可）。

## 不想录音：ElevenLabs Sound Effects

ElevenLabs 里除了 TTS，还有独立的 **Sound Effects（Text to Sound）**，专门做
非语言音效，比让它“读字”更合适。要点：

- 明确写 **one-shot / short / dry / close-mic / no music / no reverb / 0.3 seconds**；
- 写“pained / sharp / surprised / pained gasp / whimper”，**不要写 breathy、sensual、moan、melodic**；
- 一次生成 10–20 条，挑“起音最实、尾巴最短”的；
- 生成后仍建议走一遍上面的 `make_hurt_voice.py`（裁静音、定长、降调、去闷）。

可直接用的提示词：

```text
One short sharp cute anime-girl pained yelp "uh-ah!", stress on the first syllable,
surprised, aggressive attack, dry close-mic studio recording, no music, no reverb,
no moan, no melodic singing, 0.25 seconds.
```

```text
Soft cute girl whimper "wu...", trembling breath, hurt and weak, close-mic, dry,
no music, no reverb, 0.35 seconds.
```

```text
Muffled closed-mouth pained "mm", stifled, soft, close-mic, dry, no music,
no reverb, 0.30 seconds.
```

小技巧：

- 越短越难生成，可先要 0.5–1 s，再裁到 0.25–0.3 s；
- “呃”的爆破感来自**起音**，不是音量：后期用 8–10 ms 平滑起音 + 前 60 ms 轻度提亮，
  比 1–2 ms 硬起音更不容易听起来像“啪”；
- 想更“闷”就把 `--cutoff` 降到 6–7 kHz、`--pitch` 再降 1–2 半音。

## 三种受伤音的参考设定

| 目标 | 表演/提示词关键词 | 后期 |
| --- | --- | --- |
| 尖锐“呃啊” | 短促、惊讶、第一声最重；“uh-ah!” not “aaah” | 8–10 ms 起音、`--pitch -2`、`--presence 12`、0.26–0.28 s |
| 软“呜……” | 带哭腔、弱、气声少；whimper, weak, trembling | `--pitch -1~-3`、`--cutoff 7–9 kHz`、0.30–0.35 s |
| 闷“嗯……” | 闭嘴、鼻音、忍住痛；muffled “mm”, closed mouth | `--pitch -3~-4`、`--cutoff 6–7 kHz`、0.24–0.30 s |

多个受伤音可以都放进 `assets/audio/sfx/`，在 `game.py` 里按障碍档位/方向选择，
或者随机播一条；接入点仍是 `GameApp.audio_play()`。

## 已经生成好的整段语音（海螺 AI / MiniMax 等）

如果音色和表演已经满意，只缺“能进游戏”的格式（WAV / 44.1 kHz / 单声道 / 裁静音 / 统一响度），
用导入脚本即可，不会改音高或音色：

```powershell
python tools/audio/import_hit_variants.py 源.mp3:hit_1 另一个.mp3:hit_2
```

省略参数时使用默认的 8 条内置素材（`hit_voice/` 里的 8 个源文件），
输出到 `assets/audio/sfx/hit_1..8.wav`。游戏里受伤时从启用的几条里随机播一条，
启用列表由 `custom/profile.json` 决定（默认受击启用前 3 条）；完整列表见
`assets/audio/README.md`。

如果多条素材的**语调**仍然不统一，再用 `tools/audio/transfer_intonation.py`
把它们统一到同一条音高轮廓，见 [`语调统一指南.md`](语调统一指南.md)。

## 版权与音色

- 克隆/转换音色前确认授权：不要直接使用视频歌曲里的人声做参考。
- 免费素材看许可：CC0 最省心；CC-BY 要署名；平台素材可能仅限平台内使用。
- 自己录的“呃/呜/嗯”只有你的表演，没有版权问题（配乐除外）。
