# 把多段受伤音的语调改成同一套

四段素材（2 条近似“哎呀”、2 条近似“呃啊”）音色和细节都满意，但语调不统一，
放在一起会像四个人在叫。这里记录一套可重复、离线、不依赖云服务的做法。

## 先说结论

- **不要用“音色克隆 / 声音转换”**：ElevenLabs 的 Voice Changer（Speech to Speech）、
  RVC、GPT-SoVITS、Seed-VC 改的都是**音色**，而且会尽量保留输入原来的语调——
  正好是我们要改的那个东西。所以你会觉得“克隆/音色修改不好用”，不是你操作错了。
- **要改的是语调（prosody）**：音高轮廓（F0）、节奏、重音。做法叫
  **语调迁移 / prosody transfer**：把参考录音的音高旋律套到目标录音上，
  目标原来的音色、咬字、气口不动。
- 本仓库已经带脚本：`tools/audio/transfer_intonation.py`（YIN 估 F0 + TD-PSOLA 重合成，
  只依赖 numpy/scipy，确定性、可批量）。

## 为什么 ElevenLabs 这类工具帮不上

| 工具 | 它改什么 | 结果 |
| --- | --- | --- |
| ElevenLabs Text to Speech | 重新“念”一遍 | 短促的非语言音容易被念成拖长的“啊——”，丢掉你喜欢的表演细节 |
| ElevenLabs Voice Changer / STS | 音色（音高、节奏跟随输入） | 音色变了，语调还是原来那条，四段仍然不齐 |
| RVC / GPT-SoVITS / Seed-VC | 音色 | 同上，而且是“把 A 的声音换成 B 的音色”，不是“把 A 的语调改成 B 的” |
| Melodyne / Praat | 音高曲线本身 | 这才是对的方向 |

一句话：**克隆解决“像谁”，不解决“怎么叫”。**

## 本仓库脚本怎么用

### 1. 看四段的语调

```powershell
python tools/audio/transfer_intonation.py --report `
    tools/audio/source/takes/aiya1.mp3 tools/audio/source/takes/aiya2.mp3 `
    tools/audio/source/takes/ea1.m4a tools/audio/source/takes/ea2.m4a

python tools/audio/plot_contours.py `
    tools/audio/source/takes/aiya1.mp3 tools/audio/source/takes/aiya2.mp3 `
    tools/audio/source/takes/ea1.m4a tools/audio/source/takes/ea2.m4a `
    -o art_preview/intonation/contours_original.png
```

### 2. 选一个模板，把另外三段改成它

```powershell
python tools/audio/transfer_intonation.py `
    -r tools/audio/source/takes/ea1.m4a `
    -t tools/audio/source/takes/aiya1.mp3 tools/audio/source/takes/aiya2.mp3 `
       tools/audio/source/takes/ea1.m4a tools/audio/source/takes/ea2.m4a `
    --outdir art_preview/intonation/template_ea1 `
    --strength 1.0 --trim --peak 0.9 --bare
```

`-t` 里把模板自己也放进去也没关系：它会被还原成自己（自检）。

### 3. 试听

```powershell
python tools/audio/audition_intonation.py --set ea1 --ab
```

`--ab` 会先放原声、再放统一后的版本；`--set ea1` 后面还可以加 `--concat` 生成整组连播。

## 参数

| 参数 | 作用 | 建议 |
| --- | --- | --- |
| `--strength` | 采用模板旋律的程度，0–1 | 默认 0.85；要“完全统一”用 1.0；想保留目标自己的小走音用 0.7–0.85 |
| `--offset` | 整体升降调（半音） | 想统一音区时用；一般 0 |
| `--register keep/match` | `keep` 保留目标自己的中位音高；`match` 连音区也对齐模板 | 默认 keep；觉得四段高低差明显时用 match |
| `--no-keep-extremes` | 连目标的气泡音/气声也按模板改写 | 默认不开启（保留更自然） |
| `--trim` | 裁掉首尾静音 | 接进游戏时建议开 |
| `--peak` | 输出峰值 | 默认 0.9；游戏内 0.6–0.9 都行 |
| `--speed` | 时长缩放（不改变音高） | 想把四段拉成同样长时用；不建议超过 ±15% |
| `--identity` | 自检：按自己的语调重合成一遍 | 用来确认 PSOLA 没有失真（重建 SNR 一般 55 dB 以上） |

## 原理（够用版）

1. **YIN** 逐帧估基频 F0，做清浊判断、短缺口填补、局部倍频纠错、中值平滑。
2. 以各段“有声段”的归一化时间对齐，把模板的 F0 曲线换算成半音形状。
3. 目标 F0 = 目标自己的中位音高 × 模板的半音形状（`strength` 控制混入多少自身旋律）。
4. **TD-PSOLA**：按基音周期把波形切成 2 个周期的 Hann 窗，再按目标周期叠回去。
   窗与窗之间只改间距、不改共振峰，所以音色和咬字不变。
5. 清音/气声段直接沿用原波形，边界 3 ms 交叉淡化。

不是“变声器”，所以不会把“哎呀”变成别人的声音，也不会把“呃啊”的辅音改掉。

## 客观检查

脚本自带两个自检口径：

- `--identity`：同一段音频按自己的语调重合成，重建 SNR 一般是 **55–75 dB**（几乎无损）。
- 重合成后，用 `plot_contours.py` 看输出的 F0 曲线是否落在模板曲线上；
  `--report` 里的中位 F0、半音跨度也应与模板接近（音区由 `--register` 决定）。

对本次四段，长时平均谱（LTAS）相关系数在 **0.98–0.997**，说明共振峰/音色基本没动。

## 手动替代方案

不想跑脚本、只想修一两段时：

### Praat（免费，最权威）

1. `Open > Read from file` 打开目标音；
2. `To Manipulation`（默认 100 Hz 周期）；
3. `View & Edit`，在 Pitch 菜单里 `To Pitch Tier`（或从参考音提取 PitchTier 后
   `Manipulation > Replace Pitch Tier`）；
4. 选中参考的 PitchTier，复制到目标的 Manipulation，再 `Replace pitch tier`；
5. `Get resynthesis (overlap-add)`，保存 WAV。
6. 想只搬“旋律形状”，在 PitchTier 里先 `Shift` 到目标音区，再替换。

### Melodyne / Reaper / Adobe Audition

- Melodyne：直接拖音高曲线，语音也能编辑；适合精修，不适合批量。
- Reaper：`ReaPitch` 的 pitch envelope，或 `ReaTune` 的自动修正。
- Audition：`Effects > Pitch Shifter` 只能整体移调，改轮廓要用自动化包络。

### WORLD 声码器（进阶）

`pyworld` 把语音拆成 F0 / 频谱包络 / 非周期成分，替换 F0 后重合成，
音质通常比 PSOLA 更干净，但安装依赖麻烦；本机当前没装、也没网络，所以脚本用了纯 numpy/scipy 的 PSOLA。

## 本次结果

- 四段分析：中位 F0 分别约 474 / 474 / 539 / 452 Hz；音区接近，差别主要在**轮廓**：
  `aiya1` 前段平、结尾急降；`aiya2` 先平后 V 型回落；`ea1` 从头平滑下行；
  `ea2` 先扬后抑、结尾带气泡音。
- 已生成四组模板：`art_preview/intonation/template_{aiya1,aiya2,ea1,ea2}/`，
  每组 4 条 + 一条 `_all.wav` 连播。
- 建议先听 **`template_ea1/_all.wav`**：`ea1` 的平滑下行最接近“被打到”的自然反应，
  四段统一后差异最小；如果更喜欢戏剧性的“先撑着再掉下来”，听 `template_aiya1`。

## 已知限制

- **时长不改**：四段仍是 0.48–0.71 s。接进游戏前还要裁到统一的 0.25–0.35 s，
  并让 `game.py` 随机播放（受击已有 8 条内置、默认启用 3 条，但还没做语调统一）。
- **气泡音/气声不强行改**：`ea2` 结尾的低频气泡音会原样保留，所以它的曲线不会完全贴合模板。
- **大幅移调**（超过 ±5 个半音）PSOLA 可能出现颗粒感；本次只在 1–3 个半音内。
- 素材授权：这四段从哪来请自己确认；公开发布的游戏不要直接用来源不清的素材。
