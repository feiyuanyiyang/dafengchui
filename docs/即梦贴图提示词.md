# 即梦 AI 贴图提示词（参考图版）

> 适用：即梦 AI **网页版**，已上传一张“角色锚点”参考图。
> 目标：生成游戏可用的右向 3/4 行走帧、受击帧；左向由游戏镜像得到。

## 0. 为什么先做“锚点”

你上传的梗图（举拳、端饭碗）姿势太强。如果直接拿它生成行走帧，AI 会把“举拳/端碗”带进每一个动作。
所以先用它生成一张**干净的中性站姿**，再把这张锚点图作为后续所有帧的参考。

角色锚点要求：

- 正面偏右 3/4 侧身（约 30–45°）
- 双脚并拢、双手自然下垂
- 不举拳、不端碗、没有饭碗、没有文字、没有背景小鲸鱼
- 纯绿色背景、全身、脚不裁切、无地面阴影

## 1. 参考图模式与参数

即梦网页版不同版本叫法不同，本质是两种：

| 模式 | 用途 | 建议强度 |
| --- | --- | --- |
| 角色参考 / 人物参考 | 锁人脸、发型、服装、比例 | 0.65–0.75 |
| 图生图 / 参考图 | 锁整体形象，靠提示词改姿势 | 重绘幅度 0.55–0.7 |

- 比例：3:4
- 精细度：最高
- 每次生成：4 张，挑最稳的
- 角色漂移 → 提高参考强度；姿势不动 → 降低强度并加强动作描述

## 2. 通用负面词

```text
文字，水印，饭碗，多个角色，角色不一致，正侧面90度，纯背面，写实照片，

```

## 3.5 中间步骤：把正面锚点转成 3/4 锚点（关键）

正面锚点直接生成行走，AI 很容易“转不过身”。先用它生成一张**3/4 站姿锚点**，
再拿这张去生成行走 A/B，角度会稳很多：

```text
以参考图中的角色为唯一形象标准：同一张脸、同一蓝发、同一女仆装、同一鲸鱼尾巴、同一头身比。
只改变身体朝向：让角色整体向右转约45°，形成右前3/4侧身；脸朝右前方，
能同时看到面部和身体侧面；双脚并拢，双手自然下垂，保持中性站姿。
全身完整，脚不裁切，纯绿色背景，无阴影，无文字，无饭碗。
Q版游戏角色立绘，粗描边，平涂，柔和体积感。
```

检查这张图：约 45°、不是 90° 正侧面、不是纯正面；脚底完整。合格后再进入下一步。

## 8. 关于“DeepSeek娘”这个名字

- 可以写，但**名字只是弱提示**；角色一致性主要靠参考图。
- 如果即梦对“DeepSeek”相关词审核或明显跑偏：删掉名字，保留外观描述 + 参考图即可。
- 参考图锁定的只是**这一版**二创形象（蓝发女仆 + 鲸鱼尾巴）；网上不同画师的 DeepSeek 娘服装并不统一，选一版锁死就好。
- 个人使用没问题；公开发布建议做成“同风格原创角色”，避免商标/二创争议。

## 9. 生成后怎么进游戏

```powershell
# 单帧 + 脚本自动起伏（最省事）；--crop-bottom 去掉即梦右下角水印
python tools/art/import_player.py 行走A.png --bg auto --tolerance 55 --crop-bottom 160

# 如果你生成了 A/B 两帧和受击图，先发我，我给导入脚本加 --walk0/--walk1/--hurt
```

游戏只读取：

```text
assets/sprites/player/player_e_idle.png
assets/sprites/player/player_e_walk0.png
assets/sprites/player/player_e_walk1.png
assets/sprites/player/player_w_*.png        （e 的镜像）
assets/sprites/player/player_hurt.png
```
